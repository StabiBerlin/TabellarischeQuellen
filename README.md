# Data and Code for the Workshop [Tabellarische Quellen zwischen Geschichtswissenschaften und Digital Humanities](https://lab.sbb.berlin/tabellarische-quellen/)

Materials for the hands-on session on table transcription and extraction, including
example tables, ground truth (GT) transcriptions, and outputs from different
extraction tools/methods.

## Repository structure

```
data/
  sbb/
    raw-tables/     Small selection of Source images of tables from the SBB dataset   
tasks/               Markdown files with instructions for specific workshop tasks

```
