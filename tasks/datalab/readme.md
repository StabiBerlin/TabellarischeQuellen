# Workshop: Tabellenextraktion aus Bildern und Scans

In diesem Workshop extrahieren wir Tabellen aus Bildern und Scans
mithilfe der DataLab API und einem interaktiven Marimo-Notebook.

## Notebook ausführen

Du hast zwei Möglichkeiten, das Notebook zu starten:

### Option A: molab (empfohlen, kein lokales Python nötig)

1. Erstelle einen kostenlosen Account auf [molab.io](https://molab.io)
2. Öffne das Notebook direkt: [![Open in molab](https://molab.marimo.io/molab-shield.svg)](https://molab.marimo.io/notebooks/nb_56f2stoWk2eEh6oB97hYt3)
3. Fertig — alles läuft im Browser

### Option A: Marimo lokal (kein Account nötig)


1. **Python installieren** (empfohlen: Version 3.10 oder neuer)
2. **Marimo und Abhängigkeiten installieren**
```bash
   pip install marimo
   pip install -r requirements.txt
```
3. **Repository herunterladen**
```bash
   git clone https://github.com/StabiBerlin/TabellarischeQuellen.git
   cd tasks/datalab
```
4. **Notebook starten**
```bash
   marimo edit datalab-tables.py
```
